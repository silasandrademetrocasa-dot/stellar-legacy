STELLAR LEGACY • FASE 3 V48.3.0 + HOTFIX NAVE V48.2.7
PACOTE ÚNICO PARA O INSTALADOR UNIVERSAL DO GITHUB

Este ZIP é uma atualização/patch de instalação, NÃO é o repositório completo.
Não descompacte o ZIP no GitHub: o instalador universal deve receber o próprio .zip.

CONTEÚDO
1. Autopilot continua na troca de mapas e durante reconexão temporária.
2. Checkpoint do bot na aba (sessionStorage). Se a página recarregar,
   tenta retomar por até 3 minutos, apenas após revalidar a permissão
   com o servidor e reencontrar o personagem online.
3. Armazena o mapa selecionado como destino final. Regressa até X-1
   para vender/reabastecer pelo grafo de portais liberados, depois volta
   ao destino configurado.
4. Não aciona o mesmo portal duas vezes enquanto o salto aguarda confirmação.
   Recalcula rotas e encerra com aviso após repetidas rotas indisponíveis.
5. Venda oficial com espera para sincronizar e evitar requisições repetidas.
6. Munição com estoque baixo: compra no comércio oficial na base;
   fora da base, somente com AutoBuy autorizado pelo jogo.
   Compra respeita o orçamento configurado, o saldo e o preço em CR.
   Após 3 compras recusadas, para com mensagem de diagnóstico.
7. Caso a munição laser selecionada acabe, tenta equipar munição comum
   que já exista no inventário antes de retomar a batalha.
8. Mapa inicial sugerido no Autopilot: setor em que o jogador está.
9. Hotfix NAVE: minimizada em 40x40, botão N clicável e CONF 1/2 ocultos.
   Atalho alternativo em MAIS > INTERFACE / HUD > REABRIR PAINEL NAVE.
10. Testes automáticos adicionados para rotas e compra segura.

INSTALAÇÃO
1. GitHub: deixe EXATAMENTE UM .zip na RAIZ do repositório.
2. Envie este ZIP sem descompactar para a raiz.
3. Abra Actions > Stellar Legacy — Instalador Universal > Run workflow.
4. O fluxo aplicará os arquivos, executará npm run check (inclusive os
   dois patches), e rodará npm test ANTES de gravar as alterações no main.
5. Apenas se a Action for bem-sucedida, acompanhe o deploy no Render.
6. Abra o jogo com a aba atualizada para evitar cache do navegador.
