STELLAR LEGACY — V50 FROTA 3D OFICIAL (ZIP CUMULATIVO V49.5 + V50)

1) O QUE ALTERA
- Exatamente 13 naves permitidas: Aurora / phoenix, Lynx / leonov, Pioneer / liberator,
  Raptor / piranha, Valkyrie / vengeance, Bastion / bigboy, Leviathan / goliath,
  Bulwark / citadel, Seraph / aegis, Pathfinder / spearhead, Phantom / defcom,
  Kensei / yamato e Meridian / nostromo.
- Os GLB low-LOD são carregados sob demanda pelo WebGL2 nativo, sem CDN.
- Renderização de naves locais e pilotos remotos em 3D com 32 direções; GLB armazenado
  no mesmo servidor. GPU usa shader simples, sem sombras caras. Cache LRU limitado.
- Mantém sprite 2D se WebGL2/asset não puder carregar. Botão NAVE 3D: ATIVO / DESLIGADO no Hangar.
- O catálogo histórico permanece para integridade de saves, mas naves descontinuadas
  são ocultadas no Hangar, barradas na troca e bloqueadas na compra.
- Nave ativa fora do catálogo muda para Aurora ao carregar/salvar; propriedade histórica,
  moedas, inventário, drones e histórico são preservados.
- O normalizador ORIGINAL do jogo devolve equipamento acima da capacidade de Aurora
  ao inventário, respeitando regras atuais de nave e equipamentos.
- Naves especiais aprovadas mantêm requisitos/eventOnly e não ficam grátis.
- Nenhum sistema de combate, velocidade, dano, mineração, autopilot, rotas ou NPC é alterado.

2) DEPLOY ÚNICO
- Este ZIP tem o patch cumulativo da V49.5 mais a V50. Não é um jogo standalone.
- Suba SOMENTE este ZIP na raiz do GitHub do Stellar Legacy.
- GitHub Actions -> Instalador Universal -> Run workflow.
- O instalador deve executar npm run check, cujo final valida V50, e o Render fazer
  auto-deploy caso esteja conectado à main.
- Se o patch falhar por âncora do game.js ter mudado, a Action deve abortar em vez de
  fazer substituições às cegas. NUNCA usar rsync --delete manual sem o instalador.

3) SUPABASE — APÓS CONFIRMAR O DEPLOY
