# Instalacao V22.0.1

1. Nao e preciso executar SQL: esta atualizacao muda somente a formula de deslocamento do cliente.
2. Coloque apenas o ZIP completo na raiz do GitHub e use Actions > Instalar versao do Stellar Legacy > Run workflow.
3. Aguarde o Render publicar a versao 22.0.1; confira `/health`.
4. Teste VEL no painel de nave antes/depois: o numero fica igual; em mapas X-1 a X-8 e 4-1 a 4-3 a distancia percorrida por segundo cai 28%.
5. Confirme conquista A/B/C e CONF 1/2, escudos, portais e combate. Nenhum save sera alterado pela instalacao.
