# STELLAR LEGACY V22.10.0 — INSTALAÇÃO DO HUD INTELIGENTE

## Instalador
1. Baixe **stellar-legacy-V22.10.0-HUD-INTELIGENTE-5-FASES.zip**.
2. Na raiz do GitHub (`main`), remova outros arquivos `stellar-legacy*.zip`.
3. Envie **apenas este arquivo ZIP intacto**; tamanho aproximado 13,4 MB.
4. Em Actions, execute **Instalar versão do Stellar Legacy** → **Run workflow**.
5. Aguarde a conclusão do workflow e o deploy do Render. Limpe o cache do PWA, se necessário.

## Após publicar
1. Faça login e acesse **CONF → JOGO → HUD Inteligente**.
2. Selecione PvE / PvP / Mineração / Imersivo.
3. Ative a troca automática de PvE/PvP se desejar.
4. Clique em **EDITAR HUD**, arraste as alças ⠿ e confirme em **CONCLUIR**.
5. Teste o atalho **HUD − / RESTAURAR HUD** durante a partida.
6. Abra Missões, Hangar, Clã, Passe, AUX e ADM e experimente **Recolher seções**.
7. No modo discreto, ataque ou receba dano para conferir que os painéis secundários reaparecem.
8. Teste as munições, mísseis, skill quadradinha e que Kamikaze permanece no AUX.

## Limites e compatibilidade
- Preferências salvas **localmente no navegador/dispositivo**, não sincronizadas entre celulares.
- Posicionamento personalizado é opt-in; por padrão, as janelas usam o dock responsivo já existente.
- Perfis e recolhimento modificam somente a apresentação; não desbloqueiam recursos.
- Nenhum SQL precisa ser executado.
- Testes locais não substituem confirmação após deploy no Render.
