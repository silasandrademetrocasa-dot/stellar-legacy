# Stellar Legacy V13.1.0 — WARFRONT

Atualização focada em endgame cooperativo/competitivo.

## Instalação
1. Suba os arquivos desta pasta no Git/Render.
2. No Supabase SQL Editor, execute `sql/CURRENT_BACKEND.sql`. Se sua base já está na V13, pode executar apenas `sql/V13_1_WARFRONT.sql`.
3. Confirme as mesmas variáveis `SUPABASE_URL` e `SUPABASE_PUBLISHABLE_KEY` no Render.
4. Reinicie/deploy o serviço.

## WARFRONT
O botão **WARFRONT** abre World Boss, Guerra de Clãs, Mastery e Blueprint Forge. O World Boss aparece como encontro físico quando o jogador está em um mapa BATTLE (4-1/4-2/4-3) e toca em **ENGAJAR**.

## Controles
- `E`: habilidade da nave
- `K`: Kamikaze do P.E.T.
- `W`: WARFRONT
