STELLAR LEGACY V19.0.7 — CORREÇÃO ADM PORTAIS ASTRAIS

PACOTE COMPLETO • Instalador original: .github/workflows/stellar-installer-main.yml

O QUE FOI CORRIGIDO
1. Referência UI da aba Portais Astrais não estava registrada, deixando o conteúdo escondido.
2. Editor de ondas ficou independente do carregamento dos preços do Materializador.
3. Editor não fica escondido pelo recolhimento automático; os rounds continuam expansíveis.
4. Erros de carregamento dos Portais aparecem na própria aba.
5. Alterações não salvas no editor de ondas são preservadas quando os preços recarregam, e a aba sinaliza o estado sujo.
6. Versão e parâmetros de cache alterados para V19.0.7.

COMO INSTALAR (MESMO PROCEDIMENTO DE SEMPRE)
1. No GitHub, raiz de stellar-legacy / main, remova QUALQUER ZIP antigo com nome stellar-legacy*.zip, se houver.
2. Envie somente stellar-legacy-V19.0.7-ADM-PORTAIS-CORRIGIDO.zip para a raiz.
3. Actions > 🚀 Instalar versão do Stellar Legacy > Run workflow.
4. Aguarde a instalação, seguida do deploy automático do Render.
5. Faça Ctrl+F5 no jogo, abra ADM > PORTAIS ASTRAIS > AURORA.
6. Edite uma quantidade de NPC em uma onda, salve, troque de aba, retorne e confira.

NÃO HÁ MIGRAÇÃO SQL NOVA. A SQL da V19.0.6 já precisa estar aplicada no Supabase.
Não muda login, salvos, personagens, NPCs reais, preços, sorteios ou economia.
A fase 03 (criação de novas missões, receitas, temporadas e editor de leilão) é um desenvolvimento separado.

ATENÇÃO: Não envie um ZIP parcial para o instalador original. Este arquivo é a árvore completa.
