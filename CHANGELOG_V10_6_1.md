# V10.6.1 — Auction 100k Hotfix

- Corrigido o primeiro lance quando o preço do SISTEMA está em 100.000 CR.
- Enquanto não existe jogador liderando, o preço exibido pelo SISTEMA é também o lance mínimo aceito.
- Exemplo: SISTEMA 100.000 CR -> jogador pode dar 100.000 CR.
- Após o primeiro lance real, o sistema congela e nunca cobre o jogador.
- A partir daí, outro jogador precisa superar o líder em pelo menos 100.000 CR.
- Normalização do campo de lance reforçada para passos de 100.000 CR.
