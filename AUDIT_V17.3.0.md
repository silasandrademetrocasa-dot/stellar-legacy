# AUDIT V17.3.0 — FX REVAMP

## Escopo
Polimento visual de combate sem alterar dano, economia ou regras de gameplay.

## Entregas
- Perfis visuais distintos para todas as munições laser.
- Efeito visual dedicado para SIP-2 / shield drain.
- Trilhas de mísseis aprimoradas.
- Shield hit / shield regen / repair FX.
- Explosão multicamada + shockwave.
- Portal depth rings.
- Mesma renderização de laser aplicada a jogadores remotos.

## Performance
Os novos efeitos continuam respeitando `qualityProfile().fx`; em qualidade baixa o jogo mantém o caminho leve existente.
