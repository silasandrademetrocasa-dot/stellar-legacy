# Stellar Legacy V70 — Atualização do renderizador Canvas 2D

Versão base: **47.7.25** (V69), nova versão: **47.7.26**.

1. Instale o ZIP no GitHub pela rotina `Stellar Legacy — Instalador Universal`.
2. A V70 mantém mapas, NPCs, animações e gameplay da V69; não executa SQL.
3. O instalador remove 30 PNGs repetidos **somente após atualizar seus 30 manifestos**.
4. Ative o diagnóstico no menu de qualidade e faça testes reais em celulares antes de declarar vitória do Alto.
5. Caso haja regressão, utilize o ZIP específico de rollback V69 ou reverta o commit.

Arquivos importantes: `RELATORIO_TECNICO_V70.md`, `INVENTARIO_ASSETS_V70.csv`, `public/modules/adaptive-resolution-v70.js`, `public/modules/preview-scheduler-v70.js`.
