# Stellar Legacy V68 — mapas modulares V2 + sprites NPC refinados

Pacote **cumulativo desde a V67 (47.7.23)**. Instala versão **47.7.24**; não instale o ZIP V68 antigo de sprites antes deste. A V65/V66/V67 deve ter sido instalada previamente.

**Inclui:** 34 sprites NPC refinados, 30 layouts para 3 facções (X-1 a X-8), três setores 4-X e três setores U, backgrounds locais em baixo, biblioteca de PNG originais sem cópias de elementos, backgrounds WEBP otimizados, geração de cenários estável, baixo/médio/alto e parallax apenas visual.

O menu **AUTO/ALTA/MÉDIA/BAIXA** existente continua válido. O jogo só solicita `layout.json` do mapa aberto e seus sprites visíveis; caso um manifesto falhe, mostra o cenário antigo.

**Limitações honestas:** pacote fornecido dispõe de **8 fundos distintos** para 30 mapas, então alguns planos de fundo são compartilhados, embora cada mapa tenha layout e seed próprios. U-1 e U-3 ainda usam o fundo violeta disponível; telas com fundo azul e esmeralda próprios exigem novas artes. Meteoros e Efeitos não vieram no ZIP. Os fundos da biblioteca contêm algumas nebulosas/estrelas já pintadas, que não podem ser desmembradas perfeitamente. Todos os PNGs aceitos passaram na checagem de dimensão e transparência; inspeção visual final no celular deve ser realizada após o deploy.

Este pacote altera apenas apresentação gráfica e versionamento; **não executa alterações SQL, não altera drops/HP/XP/spawns, não reseta usuários**.
