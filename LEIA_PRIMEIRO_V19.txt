STELLAR LEGACY V19.0.3 — CENTRAL ADM DE CUPONS
================================================
1. Envie este ZIP completo pelo instalador GitHub de sempre.
2. Aguarde Render atualizar. No navegador use Ctrl+F5 se necessário.
3. SQL V19.0.3 já foi aplicado no Supabase: NÃO execute novamente.
4. Entre com conta ADM: ADM → CUPONS.
5. Preencha título, código (ou deixe gerar), resgates, nível, datas; escolha prêmios pelo catálogo e clique em + ADICIONAR PRÊMIO.
6. Confira até 12 prêmios na lista, clique CRIAR CUPOM, copie o código e distribua.
7. O jogador resgata na Loja Premium → Resgatar cupom de evento.
8. Ao resgatar Premium/Passe: a temporada precisa estar ativa; a mesma conta só pode usar o cupom uma vez.
9. Nave já pertencente à conta ou drones sem espaço fazem o resgate falhar sem consumir cupom; altere a combinação antes de criar.
10. Os códigos antigos de cupons continuam funcionando; nenhuma compra real é habilitada por esta versão.
11. Guarde V19.0.2 para rollback do código. Banco preserva os novos cupons mesmo num rollback de código; no código antigo eles só voltam a funcionar ao atualizar novamente.
