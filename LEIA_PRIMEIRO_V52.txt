STELLAR LEGACY V52.0 — PACOTE UNICO CUMULATIVO (V49.5 + V50.1 + V52)

OBJETIVO
- Rotação de todas as naves em tempo real corrigida (ângulo invertido no V50.1)
- Loja, Hangar e HUD exibem miniaturas dos MESMOS 13 modelos 3D atuais
- AUX-9: card/Loja/equipamento/mundo atualizados (GLB + PNG fallback)

INSTALAR
1. O ZIP substitui o pacote V50.1; instale NO MESMO GitHub Actions Universal.
2. O npm run check aplica V49.5, V50.1 e V52 em ordem (são scripts idempotentes).
3. Executa v52-verify.mjs para validar 24 modelos GLB e 37 previews PNG.
4. Não executar o SQL V50 novamente; a restrição de 13 naves já está aplicada no seu Supabase.
5. Teste em celular (comparar FPS 2D/3D; Hangar, Loja, AUX, minério, boss, farm, troca de mapa).
