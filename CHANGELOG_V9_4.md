# V9.4 — Progress Protocol

- Removidas missões de eliminação genérica das categorias diária e semanal.
- Diárias e semanais agora exigem sempre um NPC específico.
- Missão mensal continua podendo contar eliminações gerais.
- Aba Especial virou também a campanha de progresso permanente.
- Linha de progresso: Streuner → Lordakia → Saimon → Mordon → Devolarium → Sibelon → Boss Devolarium → Boss Sibelon.
- Cada etapa especial é desbloqueada somente após resgatar a etapa anterior.
- Mantida a regra de apenas 1 missão ativa por categoria.
- Nenhum progresso é contado antes do jogador clicar em ACEITAR.
